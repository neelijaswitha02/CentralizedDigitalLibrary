# Centralized Digital Library Catalog

## 📚 Project Description

The Centralized Digital Library Catalog is a web-based application developed using Python, Flask, SQLite, HTML, and CSS. It allows users to browse books, search for books, filter books by category, and view detailed information about each book.

The system also provides an admin dashboard to manage book records and track library statistics.

## 🎯 Objectives

- To maintain book information in a centralized database.
- To make searching and browsing books easier.
- To organize books based on categories.
- To manage book availability and borrowing status.
- To provide an admin interface for managing library records.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python and Flask
- **Database:** SQLite
- **Development Tools:** Visual Studio Code, Git, and GitHub

## ✨ Features

### User Features
- View the available book catalog.
- Search books by title or author.
- Filter books by category.
- Sort books by title or author.
- View detailed book information.
- Borrow available books.
- Return borrowed books.

### Admin Features
- Add new books.
- Edit existing book details.
- Delete book records.
- Enter ISBN information.
- Update book availability status.
- View total books and category-wise statistics.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/neelijaswitha02/CentralizedDigitalLibrary.git
cd CentralizedDigitalLibrary
```

### 2. Create a Virtual Environment

```bash
python3 -m venv .venv
```

### 3. Activate the Virtual Environment

For macOS or Linux:

```bash
source .venv/bin/activate
```

### 4. Install Flask

```bash
pip install flask
```

### 5. Run the Application

```bash
python app.py
```

### 6. Open in Your Browser

Visit:

```text
http://127.0.0.1:5000
```
